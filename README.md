# O-Cleaner · 磁盘清理助手

**Windows 原生、零第三方依赖、本地运行的磁盘清理与空间透视工具。**

一个本地网页界面（WebUI）：双击启动，浏览器里看清每个盘的空间被谁占着，
自己勾选要清的东西，删前逐项确认。所有逻辑跑在本机 —— **不联网、不上传、不装依赖**。

> 详细使用说明 → **[docs/USAGE.md](docs/USAGE.md)**

---

## 为什么用它

| | |
|---|---|
| **零依赖** | 只用 Python 标准库，不需要 pip 装任何包。整个文件夹拷到任何装了 Python 3 的 Windows 上双击即用 |
| **不联网** | 没有云、没有账号、没有遥测。扫描与删除全在本机完成 |
| **先看再删** | 默认不删任何东西；每项都有「是什么 / 能否重建 / 删除影响 / 建议保留」四项说明 |
| **硬护栏** | 系统目录、程序本体、用户文档被硬性拒绝，配置改坏也不会越界（见下） |
| **看见大头** | 全盘扫描按体积降序，最大项一眼可见，可逐层下钻到任意深度 |
| **快** | 检测到 WizTree 就走 MFT，C 盘全盘扫描 258 秒 → **21 秒** |

## 快速开始

1. 确认有 Python 3（命令行 `python --version` 能出版本号即可）
2. 双击 **`start-ocleaner.bat`**
3. 浏览器自动打开 `http://127.0.0.1:8770/`

> **那个黑色命令行窗口就是服务本体，清理期间别关它。** 关掉 = 停服务。

清理系统目录（Windows 更新缓存、系统日志等）需要**管理员身份**运行：
开始菜单搜 `cmd` → 右键「以管理员身份运行」→ `cd /d "你的 O-Cleaner 目录"` → `start-ocleaner.bat`

| 参数 | 作用 |
|---|---|
| `--port 9000` | 指定端口（默认 8770，被占用自动往后找） |
| `--no-browser` | 启动时不自动打开浏览器 |
| `--scan-only` | 只打印文字版扫描清单，不开服务（可配 `--drive D`） |
| `--fullscan-only` | 只跑全盘扫描并输出占用树 |

## 能清理什么

预定义目标覆盖常见位置（`Windows\Temp`、更新缓存、回收站、各类开发与浏览器缓存…），
一键预设直接可用：

| 预设 | 作用 |
|---|---|
| **安全清理** | 只选「删掉会自动重建」的项，最稳妥 |
| 深度清理 | 再加显卡着色器缓存、缩略图、崩溃转储、系统日志 |
| 开发者清理 | 只清 uv / pip 包缓存 |
| 只清回收站 | 可展开挑单个大文件 |

数据盘的大头往往在长尾的个人软件里，常规扫描还会**自动发现**本盘顶层被知识库
判定为可清理的目录（橙色标记）—— 实测某数据盘从 3 个可清理项涨到 11 个，
几十 GB 从「看得到」变成「能直接勾」。识别规则与误判防线见
[docs/USAGE.md](docs/USAGE.md#自动发现数据盘能用的关键)。

## 空间透视

- **全盘扫描** —— 一键扫描本盘，默认展示「全盘最大项目」，可切「本层目录 / 只看文件 / 全部可清理」
- **逐层下钻** —— 点开任意目录拆二级、三级……实测每层 1–4 毫秒，不受扫描树深度上限约束
- **细分查看** —— 把一个目录拆成「① 能删的缓存子目录 / ② 千万不要删」，逐项给体积和理由。
  它先判断目录**真实身份**（浏览器资料目录 / 游戏安装目录 / 无法确定），再决定怎么说话
- **Steam 游戏库** —— 不扫盘，直接读 Steam 清单：30 余款游戏 0.6 秒读完，可按「最久没玩」排序，
  并列出**磁盘上存在但 Steam 已无记录的残留目录**

## 安全设计

**硬性拒绝**以下删除目标，即使 `config\targets.json` 被改坏也不会越界：

- 盘符根目录本身，以及在根目录直接删文件
- `Windows`、`Program Files`、`ProgramData`、`Users`、`Recovery` 等系统目录
- 任何层级出现的 `System32`、`SysWOW64`、`WinSxS`、`Installer`、`servicing`、`Boot`
- `$Recycle.Bin`、`System Volume Information` 目录本身（回收站走专用清理接口）
- 用户主目录 `%USERPROFILE%` 及 `%USERPROFILE%\AppData`

**不会触碰**：用户文档 / 图片 / 桌面、已安装程序本体、已下载的 AI 模型、
`Windows\Installer`、`WinSxS` 组件存储。

删除是**直接删除**（不进回收站），执行前弹窗逐项列出确切路径、大小、文件数。
被占用的文件会**跳过而不是报错**，权限不足的项会被点名，同批次其余项照常清理。

## 换台电脑也能用

路径全部走 `%LOCALAPPDATA%`、`%USERPROFILE%` 这类变量，**不写死盘符和用户名**。
整个文件夹拷进 U 盘 → 插到另一台 Windows → 双击 bat 就能用，盘符、用户名、可用空间自动识别。
唯一要求：装了 Python 3。

## 常见问题

**网页打不开？** 看黑窗口打印的「界面地址」，端口被占用时会自动往后找。

**提示「需要管理员权限」？** 正常现象。`Windows\Temp`、更新下载缓存等本来就要提权，同批次其它项仍会正常清理。

**提示「X 项被占用」？** 浏览器 / 剪辑软件 / Python 正在用这些文件，关掉相关程序再来一次。

**清理后游戏变卡？** 清了 NVIDIA 着色器缓存，游戏首次启动需要重新编译，之后自动恢复，不会损坏游戏。

**改配置要重启吗？** 不用。所有 `config\*.json` 改完刷新网页即生效。

更多见 [docs/USAGE.md](docs/USAGE.md#十二常见问题)。

## 参与开发 / 自测

三道闸门：**规则安全 → 功能自测 → 真实浏览器渲染**，已在 Windows CI 上全绿运行。

```
python -X utf8 tools/lint_rules.py --strict     # 规则安全闸门（42 条规则，警告也算失败）
python -X utf8 tools/selftest.py                # 功能自测（302 项断言）
node tools/cdp_check.js http://127.0.0.1:8770   # 真实浏览器渲染（80 项断言，零安装）
```

**改 `config\filetypes.json` 之前必跑 linter —— 这是硬性闸门。**
`filetypes.json` 是全盘扫描的识别知识库，**一条错误的规则会真的让用户删掉不该删的东西**。
linter 会做结构校验、语义自相矛盾检测、关键词跨规则冲突，并用真实识别引擎把知识库
自己的每个关键词跑一遍验证归属。
