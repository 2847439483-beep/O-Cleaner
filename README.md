# O-Cleaner · 磁盘清理助手

Windows 磁盘清理与空间占用分析工具。本地运行，浏览器打开即用，
**绿色免安装**——不写注册表、不装服务，整个文件夹拷走就能在别的电脑用。

- **零依赖**：只用 Python 标准库，不 pip 安装任何东西；免安装版连 Python 都内嵌了
- **默认不删任何内容**：必须手动勾选并二次确认；系统目录有硬保护名单拦截
- **不采集数据**：除主动点击「下载 WizTree 便携版」外不发起网络请求

## 快速开始

**免安装版**（推荐，内嵌官方 Python 运行时）：

1. 解压到任意可写目录（U 盘也行，别放 Program Files）
2. 双击 `start-ocleaner.bat`
3. 浏览器自动打开 `http://127.0.0.1:8770/`

**便携版**（约 300 KB，要求电脑已装 Python 3）：解压后同样双击 `start-ocleaner.bat`。

> 黑色命令行窗口是服务本体，清理期间别关；关掉窗口即停止服务。
> 首次运行 SmartScreen 若提示「已保护你的电脑」：点「更多信息 → 仍要运行」
> （程序未做代码签名，属正常提示）。

常用参数：

| 参数 | 作用 |
|---|---|
| `--port 9000` | 指定端口（默认 8770，被占用自动后移） |
| `--no-browser` | 启动时不自动打开浏览器 |
| `--data-dir D:\oc-data` | 数据存档目录重定向（历史记录、配置等运行数据的存放位置） |
| `--scan-only` | 只输出文字版扫描清单，不开服务 |
| `--fullscan-only` | 只输出磁盘占用树 |

## 它能做什么

| 能力 | 说明 |
|---|---|
| 空间占用分析 | 全盘按体积排行、逐层下钻；默认快速扫描先定位占地大头，深层目录随时可点开细看 |
| 清理勾选 | 可清理项直接在排行里勾选；每项写明「是什么 / 能否重建 / 删了有什么影响 / 什么情况该留」 |
| 一键预设 | 安全清理 / 深度清理 / 开发者清理 / 只清回收站 |
| Steam 游戏库 | 读 Steam 清单秒级列出游戏体积与中文名，没在玩的游戏可整目录删除（带存档提示与二次确认）；还能列出卸载残留 |
| 扫描加速 | 可选 WizTree MFT 加速（界面一键下载便携版）；没有它也能用，只是慢一些 |
| 被占用文件 | 删不掉时列出**可能**占用文件的程序候选，由你自行退出后重试，不代关进程 |

## 数据与迁移

- **数据存档目录**：历史记录、配置、定时任务等运行数据全部集中在程序目录内
  （默认）或 `--data-dir` 指定的目录。界面右栏「运行环境自检」会显示它的位置。
- **U 盘携带**：把整个 O-Cleaner 文件夹放进 U 盘，插哪台电脑都能直接跑，
  数据就写在 U 盘上；拔下即带走，不留痕迹。
- **换机迁移**：整个文件夹复制过去即可，路径不含固定盘符与用户名；
  自定义释义、换算单位、固定项规则还可导出成 JSON 单独带走。

## 安全边界

以下目标**永远不会被删除**（即使配置文件被改坏也拦得住）：
盘符根目录、`Windows`、`Program Files`、`ProgramData`、`Users`、
`System32`/`WinSxS`/`Installer` 等系统组件、用户文档与桌面、已安装程序本体、
已下载的 AI 模型。资源包只能补充说明文案，改不了「删不删」的结论；
AI 只能勾选候选，不能执行删除。

删除按风险分级：高风险项默认移入回收站（可恢复，可在界面关闭），中/低风险缓存类直接删除（进回收站只会白占空间）；执行前逐项列出路径、体积与文件数。
完整安全模型与对抗性测试见 [SECURITY.md](SECURITY.md)。

## 常见问题

**网页打不开**：看命令行窗口的「界面地址」一行；端口被占会自动后移。

**提示需要管理员权限**：`Windows\Temp`、更新缓存等需要提权，右键
`start-ocleaner.bat` → 以管理员身份运行；同批其余项目不受影响。

**部分文件被占用**：浏览器、剪辑软件等正在使用，关掉相关程序再清。

**清理后游戏首次启动变慢**：清了着色器缓存，重新编译一次即恢复，不影响游戏。

**改了配置要重启吗**：不用，刷新网页即生效。

完整说明见 [docs/USAGE.md](docs/USAGE.md)。

## 文件一览

| 位置 | 内容 |
|---|---|
| `start-ocleaner.bat` | 启动脚本（双击运行的就是它） |
| `app.py` | 主程序：扫描、占用分析、清理执行、HTTP 服务 |
| `web\index.html` | 界面（单文件） |
| `config\targets.json` | 预定义清理目标（可自行增删条目） |
| `config\filetypes.json` | 识别知识库：什么目录算垃圾、能不能删 |
| `packs\` | 内置资源包（补充释义，可导入第三方包） |
| `tools\selftest.py` 等 | 自测与检查脚本（`lint_rules.py` 校验知识库与资源包；改动配置后建议跑一遍） |
